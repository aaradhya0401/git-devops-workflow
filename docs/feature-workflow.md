# Feature Branch Workflow

## Purpose
This document demonstrates how to develop a feature using Git branches.

## Workflow
1. Create a feature branch from the development branch.
2. Make changes in the feature branch.
3. Commit the changes.
4. Push the feature branch to GitHub.
5. Open a pull request for review.
6. Merge the approved pull request into the target branch.

## Benefits
- Keeps feature development separate from stable code.
- Makes changes easier to review.
- Supports collaboration and version control.
